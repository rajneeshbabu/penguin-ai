🐧 PENGUIN AI
Hello! I'm Penguin AI. Ask me anything — I support General Chat, Document Q&A, Agentic reasoning, and Domain Expert modes. What would you like to explore?

🔬 Multilingual Production RAG Pipeline

📥 Document Upload → ✂️ Semantic Chunking → 🔑 SHA-256 Dedup → 🌍 Multilingual Embed (50+ langs) → 🔀 BM25 + FAISS Hybrid → ⚖️ RRF Fusion → 🎯 mMiniLM Rerank → 📌 Citations + Cache → 🤖 LLM Answer (same language)

🧠 RLHF — Reinforcement Learning from Human Feedback

PPO-style reward model that adapts the chatbot's behaviour in real-time based on your 👍/👎 feedback — no GPU needed.

👍👎 Human Signal → ⚖️ Reward Model → 📊 Value Baseline → 📈 Advantage → 🔄 Policy Update → 🎯 Better Responses

✨ Features

🤖

General Chat

Conversational AI with 20-turn sliding memory window. RLHF policy adapts temperature to your preferences.

🌍

Multilingual RAG

Ask in Hindi, French, German, Spanish, Japanese or 46 more languages — multilingual embeddings map cross-lingual queries to documents natively. Auto language detection badges your query language in the UI.

📄

Advanced RAG

Upload PDF/DOCX/TXT. 6-layer pipeline: semantic chunks → multilingual BM25+FAISS → RRF → mMiniLM rerank → citations.

🕵️

Agentic RAG

ReAct loop with multi-hop retrieval (up to 3 hops). LLM reasons, picks tools, and self-corrects.

🧠

Domain Expert

6 specialised personas: Medical · Legal · Finance · Code · Fitness · Research.

🎙️

Whisper Multilingual

Upload any audio in any language — Whisper auto-detects and transcribes in 99 languages via Groq's Whisper API.

🛡️

Safety Guard

Llama Guard 3 20B checks every response for harmful content before it reaches you.

🚀 Quick Start

1

Clone

git clone https://github.com/rajneeshbabu/penguin-ai.git
then
cd penguin-ai

2

Install

/opt/anaconda3/bin/pip install -r requirements.txt

3

API Key

Get a free key at console.groq.com then:
echo "GROQ_API_KEY=gsk_..." > .env

4

Run

streamlit run app.py
Opens at localhost:8501
